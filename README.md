# /kaishoku — 会食レストラン候補出しスキル

会食・接待のレストラン候補を **5店** リストアップする [Claude Code](https://claude.com/claude-code) スキル。
エリアと日時を渡すと、食べログ／Googleマップの評価で絞り込み、個室の有無・食事制限の対応可否まで確認した比較表と推奨ランキングを返す。

> A Claude Code skill that shortlists 5 restaurants for Japanese business dinners — filtered by Tabelog / Google Maps ratings, with private-room availability and dietary-restriction checks. Japanese-language skill.

## なぜ作ったか

会食のたびに「エリア・評価・個室・アレルギー」を毎回ゼロから検索し直していた。
判断に必要な項目は毎回同じなので、**探す基準そのもの**をスキルに固定した。

## インストール

```bash
git clone https://github.com/fyuma68/kaishoku-skill.git ~/.claude/skills/kaishoku
```

`~/.claude/skills/kaishoku/SKILL.md` が置かれれば有効になる。プロジェクト単位で使う場合は `.claude/skills/kaishoku/` でもよい。

## 使い方

```
/kaishoku 渋谷 5/15 18:30
```

会話中に「会食」「接待」＋エリア＋日時が出てきた場合も自動で起動する。

不足している条件（人数・予算・ジャンル・食事制限・目的）は1回だけまとめて聞かれる。
答えなければ既定値（2名／8,000〜10,000円／和食／制限なし）で進む。

### 出力されるもの

1. **比較表** — 店名・ジャンル・食べログ点数・Google点数・客単価・個室・最寄り
2. **推奨ランキング上位3店** — その会食に合う理由つき
3. **注意点** — アレルギー混入リスク、予約の取りにくさ、支払い方法
4. **予約時の確認文** — 店にそのまま送れる文面

## 評価基準

候補が枯れないように2段階で運用する。

| ライン | 食べログ | Googleマップ |
|---|---|---|
| 理想 | 3.50 以上 | 4.5 以上 |
| 妥協 | 3.30 以上 | 4.2 以上 |

**5店は必ず揃える。** 妥協ラインの店には ☆ を付け、どの項目が未達かを明記する。
それでも足りない場合はエリアを1駅ぶん広げ、広げたことを出力に書く。

基準を変えたい場合は `SKILL.md` の「3. 評価基準」の表を直接書き換える。

## 個人設定

好みや過去の予約履歴を反映させたい場合、スキルと同じディレクトリに次のファイルを置く。どちらも `.gitignore` 済みで、リポジトリには入らない。

- `preferences.md` — 常用エリア、苦手ジャンル、予算感、支払い条件など（`preferences.example.md` をコピーして使う）
- `history.md` — 成立した予約の履歴。次回以降の候補出しで参照される

## 設計上の制約

- **食べログのスクレイピングはしない。** 公式APIは廃止済みで、スクレイピングは規約違反にあたる。公開検索結果と公式サイトの範囲で確認する
- **自動予約はしない。** 予約の確定は人間が行う。スキルは候補提示で止まる
- **評価点を推測しない。** 取得できなかった項目は「未確認」と出力する
